# 🎯 Quiz Interativo

Um projeto de quiz interativo feito com HTML, CSS e JavaScript, ideal para praticar conhecimentos e se divertir respondendo perguntas com feedback imediato!

## 🔧 Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript puro

## 📌 Funcionalidades

- Exibição de perguntas com múltiplas alternativas
- Resposta imediata com feedback visual (correto ou incorreto)
- Contador de pontos e pontuação final
- Design responsivo (funciona em desktop e celular)
